# 🎮 Tic Tac Toe

A clean, modern, single-file Tic Tac Toe game built with pure HTML, CSS, and JavaScript.

## Features

- Classic 3×3 Tic Tac Toe gameplay
- Win detection with highlighted winning line
- Draw detection
- Score tracking (X wins / O wins / Draws)
- Smooth hover effects and modern UI
- Fully responsive
- No external dependencies — just open `index.html`

## How to Play

1. Open `index.html` in any modern browser
2. Player **X** starts first
3. Players take turns clicking empty cells
4. First player to get 3 in a row (horizontal, vertical, or diagonal) wins
5. Click **Restart Game** to play again
